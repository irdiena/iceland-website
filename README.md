# IceLand Homemade Ice Candy Website

A one-page, static business website built with HTML, CSS and JavaScript.

## Files
- `index.html` — all website sections and content
- `style.css` — IceLand visual theme and responsive layout
- `script.js` — mobile navigation, smooth section reveal and current year
- `assets/` — local IceLand images used by the website

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save. GitHub will publish the site at your GitHub Pages address.
